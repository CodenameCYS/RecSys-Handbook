# 跨域迁移与少样本学习

当目标域样本不足但平台拥有其他领域、市场或任务的数据时，可以迁移稳定知识。关键不是“把旧模型拿来继续训练”，而是识别哪些表示可共享、哪些模式必须隔离，以及如何检测负迁移。

## 1. 迁移场景

| 场景 | 源域 | 目标域 | 主要难点 |
| --- | --- | --- | --- |
| 新频道 | 主站推荐 | 新内容频道 | 行为语义与供给分布不同 |
| 新国家/城市 | 成熟市场 | 新市场 | 语言、价格、文化和供给差异 |
| 跨设备 | App | Web/TV/车载 | 交互方式和会话长度不同 |
| 跨任务 | 点击预测 | 转化/留存 | 标签稀疏、延迟和目标偏移 |
| 跨品类 | 成熟类目 | 新类目 | 属性空间与购买周期不同 |

## 2. 常见方法

### 参数迁移

使用源域模型初始化目标域，再进行微调。适合特征和任务相近的场景。需要冻结部分通用层、降低学习率，并监控少量目标数据是否导致灾难性遗忘。

### 表示迁移

共享文本、视觉、用户或物品编码器，目标域只训练轻量任务头。它比整模型迁移更可控，也便于隔离业务目标差异。

### Embedding 映射

当两个域的用户或物品部分重叠时，可学习源域 Embedding 到目标域空间的映射。重叠对象是锚点；锚点覆盖不足或只覆盖高活跃用户时会产生偏差。

### 域适配

通过对抗训练、分布匹配、重要性加权或域特定归一化，让共享表示减少域差异。目标是学习域不变部分，而不是强迫所有分布完全一致。

### 多域联合学习

共享底层专家，并为每个域保留独立专家、门控和任务头。适合长期存在多个场景的平台，比一次性迁移更适合持续训练。

## 3. 元学习

元学习将“少量样本快速适配”本身作为训练目标。推荐中可以把每个用户、物品、城市或类目视为一个任务：

- Support Set：该对象的少量初始交互。
- Query Set：适配后需要预测的后续交互。
- Meta-Training：在大量历史任务上学习初始化、更新规则或度量空间。
- Meta-Test：面对未见对象，仅用少量支持样本快速调整。

典型方向包括：

- MAML 类方法：学习易于微调的参数初始化。
- 度量学习：在共享空间内通过少量样本构建原型。
- 记忆增强：存储历史任务模式，为新对象检索相关先验。
- 参数生成：根据内容与少量行为直接生成个性化参数或 Embedding。
- Neural Process：学习对象级条件分布并表达预测不确定性。

## 4. 预训练与基础模型

预训练模型提供强大的内容先验，适合新物品、新类目和跨语言场景。落地时仍需要：

1. 用推荐行为对齐通用语义空间。
2. 控制向量生成时延和在线服务成本。
3. 处理内容缺失、低质量和对抗性文本。
4. 与 ID/协同表示建立连续融合机制。
5. 通过探索获得偏好证据，而不是把语义相关性当作最终效用。

## 5. 负迁移诊断

- 与“只用目标域数据”和“简单源域初始化”两个基线比较。
- 按用户活跃度、类目、市场和时间分群，避免均值掩盖局部退化。
- 检查源/目标域标签定义、曝光策略和特征取值是否一致。
- 衡量域判别器能否轻易区分表示，识别残余分布差异。
- 对共享参数和域特定参数做消融，确认收益来自哪里。
- 观察目标域样本增长后迁移收益是否衰减，并设计退出机制。

## 6. 工业落地建议

- 先迁移内容编码器和通用行为模式，再谨慎迁移排序头。
- 为域标识、语言、市场、终端保留显式特征和独立参数。
- 使用门控控制源域知识强度，门控输入目标域样本量与不确定性。
- 在训练数据中模拟少样本任务，不能只在随机切分上验证。
- 对新市场保留规则与本地运营兜底，模型迁移不能替代供给建设。
- 建立负迁移报警：若关键分群低于目标域基线，自动降级到独立模型。
