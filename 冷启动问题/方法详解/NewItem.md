# 新物品冷启动

新物品冷启动的本质是：对象已经可以被推荐，但缺少曝光、点击、转化和共现信号，系统无法区分“潜在优质但尚未被看见”与“真实低质量”。解决方案必须同时包含**初始表示**和**反馈获取**。

## 1. 新物品进入系统的链路

1. 内容接入：校验标题、类目、图片、作者、价格、库存和合规状态。
2. 特征生成：计算文本、视觉、音频、多模态及结构化属性表示。
3. 质量预估：评估完整度、清晰度、重复度、安全、作者/商家可信度。
4. 初始召回：接入内容相似、类目、图关系和探索召回通道。
5. 受控曝光：在匹配人群和预算约束下收集反馈。
6. 统计更新：更新 CTR/CVR、置信区间、负反馈与成长阶段。
7. 模型迁移：逐步引入 ID Embedding、协同信号和序列特征。

## 2. 内容表示

### 结构化属性

类目、品牌、作者、价格带、地域、标签和发布时间易于解释与在线服务，是最稳定的基础。需要处理缺失值、新类别 OOV、错类目和属性作弊。

### 文本表示

标题、描述、正文、查询词和评论可由预训练语言模型编码。推荐空间中的相似性与通用语义相似性并不完全相同，因此通常要用点击、共现或对比学习目标做领域对齐。

### 视觉、音频与视频

图像风格、商品外观、封面、音频和视频内容能补充文本缺失。工业上常离线提取向量，并通过蒸馏或降维控制存储和 ANN 成本。

### 多模态融合

可采用拼接、加权求和、门控、Cross-Attention 或共享语义空间。需要显式处理模态缺失，避免某一模态缺失时整个表示失效。

## 3. 内容与协同融合

常见策略包括：

- 用内容网络直接生成新物品初始 Embedding。
- 让内容 Embedding 回归成熟物品的协同 Embedding。
- 训练时随机丢弃 ID/协同特征，使模型适应零交互输入。
- 将内容塔与 ID 塔并行，由交互量或不确定性控制权重。
- 用教师协同模型蒸馏内容学生模型，再在有反馈后联合更新。

一个简单连续门控可写为：

$$
e_i=\alpha_i e_i^{collab}+(1-\alpha_i)e_i^{content}
$$

其中 $\alpha_i$ 不应只由曝光次数决定，还可输入正负反馈数量、时间跨度、内容完整度和协同表示的不确定性。

## 4. 新品探索机制

### 固定流量池

为符合质量门槛的新品预留固定曝光比例。实现简单，但所有新品获得相同预算，效率较低。

### 分层漏斗

新品先获得小规模测试流量；若置信下界、负反馈和安全指标达标，再进入更大流量层。未达标者退出或等待内容修正。

### 不确定性驱动

使用 UCB、Thompson Sampling 或贝叶斯平滑，在预期收益与不确定性之间平衡。高不确定性不等于应无限探索，仍需质量和风险约束。

### 匹配人群探索

新品不应随机展示给全体用户，而应根据内容、类目、价格带和作者寻找最可能喜欢的人群。这样能以更低体验成本得到更有辨识度的反馈。

## 5. 电商新品案例

假设新上架一双跑鞋：

- 内容侧提取品牌、运动类目、缓震属性、价格带、颜色和图像向量。
- 召回侧进入“相似跑鞋”“品牌新品”“价格带偏好”和“新品探索”通道。
- 排序侧使用内容 CTR、商家质量、库存、履约和价格竞争力，屏蔽缺失的历史销量特征。
- 探索侧优先分配给近期浏览跑鞋且价格偏好匹配的用户。
- 获得足够曝光后，使用贝叶斯平滑 CTR/CVR 与同类先验比较。
- 交互成熟后，逐步提高 ID Embedding 和协同特征权重。

## 6. 成功判定与指标

- Time-to-First-Exposure、Time-to-First-Positive 与达到稳定估计所需时间。
- 新品曝光覆盖率、有效反馈覆盖率和冷启动成功率。
- 同类目归一化 CTR/CVR、负反馈、退货率和长期质量。
- 新品获得反馈的样本效率，即单位探索成本产生的有效信息。
- 成熟后表现，防止只把低质量物品靠补贴流量推过冷启动期。
- 商家、作者、类目和价格带之间的曝光公平。

## 7. 常见失败

- 只有内容模型，没有探索流量，导致新品仍无法获得验证。
- 只看原始 CTR，忽略位置、用户匹配和小样本高方差。
- 用新品上线时间替代曝光量，供给量大时大量新品实际从未被测试。
- 所有新品共享一个探索池，优质长尾被低质供给挤占。
- 忽略退货、投诉、安全和履约，短期点击高但长期价值差。
- 内容向量离线生成过慢，新品真正进入索引时已错过生命周期。
