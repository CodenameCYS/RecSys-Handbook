# 冷启动工业案例分析

本章不追求给出唯一架构，而是展示如何把对象识别、内容先验、召回排序、探索反馈、状态迁移和分群评测串成完整系统。

## 案例一：短视频新用户

### 业务目标

用户首次打开应用时，在前 10-20 条视频内建立基本兴趣判断，同时控制快速划走、不感兴趣和首会话退出。

### 初始策略

- 候选池：分地域趋势、时段热门、渠道相关、优质长尾和受控探索。
- 过滤：安全、低质、重复、语言和终端不适配内容。
- 排序：内容质量、群体先验、场景匹配与多样性约束。
- 页面编排：首批内容覆盖多个可区分主题，不连续堆叠相似视频。

### 实时学习

将有效观看、完播、复看、关注、快速划走和负反馈作为不同强度的证据。前几次行为使用较高学习率，但要求多个一致信号后再显著收窄兴趣。会话向量按主题簇维护，避免单一兴趣吞噬其他可能性。

### 状态迁移

从上下文热门逐步迁移到会话兴趣、多兴趣召回和序列模型。门控输入包括有效观看数、主题一致性、行为时间跨度与预测不确定性，而不是简单按观看次数硬切。

### 评价

观察首个有效观看耗时、前 10 条有效消费率、会话长度、次日留存、快速划走率和主题覆盖。若 CTR 上升但会话退出率也上升，通常意味着标题/封面诱导或过早收窄。

## 案例二：电商新品

### 业务目标

让符合质量门槛的新品获得验证机会，尽快识别潜在爆品，同时避免以探索名义补贴低质商品。

### 初始表示与召回

- 根据标题、类目、品牌、属性、图片和价格生成内容向量。
- 进入相似商品、类目偏好、品牌偏好、店铺新品和探索召回。
- 使用商家质量、库存、履约、价格竞争力和内容完整度形成先验。
- 对新类别/OOV 和模态缺失设置显式兜底，不默认为零向量。

### 分层探索

新品先在高匹配用户中获得小批曝光。用贝叶斯平滑 CTR/CVR、负反馈和退款风险与同类商品比较；通过门槛后扩大流量，失败则退出或等待商家完善信息。

### 反作弊

探索预算应绑定真实库存、商家信誉和异常行为检测。点击异常高但加购、成交、退款与同类显著背离时，不能自动晋级。

### 评价

新品有效曝光覆盖率、首次成交耗时、单位探索曝光获得的有效反馈、毕业率、成熟期 GMV/退款率，以及不同商家和类目的机会公平。

## 案例三：新闻文章

### 业务特点

文章生命周期短，等待协同信号成熟后再推荐往往已经过时。新闻还具有强时效、安全、观点多样性和突发事件需求。

### 决策链路

1. 发布时解析主题、实体、地域、来源、文本质量和时效性。
2. 通过内容向量进入主题与相似文章召回。
3. 用来源可信度和编辑规则完成准入。
4. Contextual Bandit 在匹配读者中分配首批流量。
5. 实时更新点击、有效阅读、分享、隐藏和投诉后验。
6. 热点衰减后及时退出，不能仅因累计 CTR 高持续占位。

### 实验注意

文章状态会被实验流量改变，因此对象级共享可能污染对照。可按用户稳定分桶并隔离策略统计，或采用 switchback 等时序实验设计。评价除点击外还需包括有效阅读、来源多样性、投诉和时效覆盖。

## 案例四：新广告创意

### 业务目标

在有限广告预算内估计新创意的点击和转化能力，并满足出价、预算、频控、品牌安全和用户体验约束。

### 冷启动先验

从广告主、行业、版位、素材类型、文本图像、落地页质量与历史相似创意构造分层贝叶斯先验。广告主历史可复用，但应防止大广告主先验长期压制新广告主。

### 探索策略

使用 Thompson Sampling 或受约束 Contextual Bandit，在满足预算和频控的候选中分配曝光。点击奖励快速但转化延迟，应使用延迟反馈修正或多任务估计，避免把暂未转化当作负样本。

### 评价

收入、广告主 ROI、预算消耗平滑度、转化延迟、用户负反馈和不同广告主的探索机会。上线时限制最坏收益下降，并配置异常素材熔断。

## 案例五：本地生活新城市

### 业务特点

新城市同时存在用户少、商户少和履约网络不成熟的问题。成熟城市的价格、距离和类目偏好不能直接照搬。

### 迁移方案

- 共享文本、图片、商户质量和通用行为编码器。
- 按城市保留独立价格归一化、距离衰减、类目先验和排序头。
- 根据人口密度、供给结构和消费水平检索相似城市作为源域。
- 使用门控融合跨城先验与本地反馈，随本地样本增长降低迁移强度。
- 运营侧先建立核心供给和可履约区域，模型不能推荐不存在的供给。

### 负迁移监控

按距离、价格带、新老商户与类目比较迁移模型和本地基线。若整体收益上升但远距离订单取消率恶化，说明共享偏好掩盖了城市履约差异。

## 案例六：社区新作者

### 双边冷启动

新用户需要找到值得关注的人，新作者需要获得首批读者。只优化用户点击会使头部作者垄断曝光；只追求作者公平又会降低内容质量。

### 方案

- 根据主题、内容质量、专业认证和社交关系构造作者先验。
- 在相关兴趣人群中分配探索流量，而不是全局随机扶持。
- 将关注、有效互动、隐藏、举报和后续持续消费共同作为奖励。
- 设置作者级曝光上限、毕业条件和低质淘汰。
- 对敏感内容、私信与关系推荐使用更严格的安全策略。

## 跨案例共性检查表

| 环节 | 必须回答的问题 |
| --- | --- |
| 定义 | 谁是冷对象？按时间、曝光、行为、新鲜度还是置信度判断？ |
| 先验 | 零交互时有哪些可信内容、上下文、关系或跨域信号？ |
| 准入 | 哪些质量、安全、库存和合规条件必须先满足？ |
| 探索 | 谁承担探索、预算多大、怎样匹配、何时熔断？ |
| 反馈 | 正负奖励如何定义，是否存在延迟、位置和曝光偏差？ |
| 迁移 | 从冷策略到常规模型如何连续过渡，是否会分数跳变？ |
| 评价 | 是否按阶段和群体报告短期收益、长期价值、成本与公平？ |
| 回退 | 特征缺失、服务超时或策略异常时使用什么稳定基线？ |
