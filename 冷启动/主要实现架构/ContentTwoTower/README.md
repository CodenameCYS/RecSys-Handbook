# Content Two-Tower

## 核心思路

新物品没有交互，但通常有类目、文本、图像、作者和价格等内容特征。物品塔把这些特征映射到与用户向量相同的空间，使新品无需先积累 ID Embedding 就可参与召回。

示例将类目与作者 Embedding 拼接后投影为物品向量；用户向量仍由用户 ID 表示。正例配对通过批内对比损失训练。真实系统可将用户塔替换为行为序列编码器，并将物品塔扩展为文本/视觉预训练模型。

- [model.py](./model.py)：用户塔与内容物品塔。
- [train.py](./train.py)：合成内容特征训练，并对未出现在正例中的新品打分。

安装 PyTorch 后执行 `python train.py`。

部署时应只依赖上线可获得的内容特征，监控缺失率、特征新鲜度和新品覆盖；并通过探索策略收集反馈，逐步与 ID/协同表示融合。
