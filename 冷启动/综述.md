# 冷启动综述

## 问题分类

| 类型 | 缺失信息 | 常见方案 |
| --- | --- | --- |
| 新用户 | 行为历史不足 | 热门/地域先验、问卷、会话兴趣、Bandit 探索 |
| 新物品 | 交互与曝光不足 | 内容塔、多模态表示、属性图、探索流量 |
| 新场景/市场 | 本域样本不足 | 跨域迁移、元学习、域适配、规则保护 |
| 系统启动 | 用户和物品交互都不足 | 内容推荐、编辑运营、外部知识与主动采集 |

## 系统闭环

1. 识别冷启动状态并记录冷启动阶段、可用信号和置信度。
2. 使用内容、画像、跨域先验或基础模型构造初始表示。
3. 分配受控探索流量，尽快收集高信息量反馈。
4. 随交互增长切换或融合到常规协同模型。
5. 分群评估首日/首周留存、覆盖、后悔值、公平和安全护栏。

## 关键风险

热门保底会形成马太效应；新物品探索可能损害用户体验；内容特征存在缺失、噪声和训练服务漂移；只在全量用户上报告均值会掩盖冷启动退化。
