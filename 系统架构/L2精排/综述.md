# L2 精排综述

## 核心问题

1. 数据与标签：曝光归因、点击/转化/时长、延迟反馈和样本选择偏差。
2. 特征与表示：用户、物品、上下文、序列、交叉特征和训练服务一致性。
3. 模型结构：Wide & Deep、DeepFM/DCN、DIN/DIEN、Transformer 和基础模型。
4. 学习目标：Pointwise、Pairwise、Listwise、多任务、时长建模和概率校准。
5. 在线推理：特征拉取、批量打分、蒸馏、量化、级联和降级。

## 方法版图

| 方向 | 代表模型 | 解决的问题 |
| --- | --- | --- |
| 特征交互 | Wide & Deep、DeepFM、DCNv2 | 低阶与高阶交叉 |
| 注意力交互 | AutoInt、FiBiNET | 自动学习字段关系与重要性 |
| 兴趣建模 | DIN、DIEN | 候选相关兴趣与兴趣演化 |
| 序列建模 | BST、SASRec、BERT4Rec | 顺序、上下文与长依赖 |
| 多任务学习 | ESMM、MMoE、PLE | CTR/CVR 等目标共享与冲突 |
| 多场景学习 | STAR、M2M | 场景间迁移与差异建模 |
| 基础模型 | 预训练、多模态、生成式模型 | 跨域迁移与规模化表示 |

每种模型应记录特征、Embedding、交互层、任务头、损失、样本口径、校准、复杂度和线上时延。
