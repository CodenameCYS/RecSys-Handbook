# ANN 与索引

## 为什么独立维护

CF、I2I、双塔和多模态模型都可能输出向量。它们的训练方式不同，但共享“向量导出、建索引、在线查询、过滤和监控”的生命周期，因此 ANN 不应在每个方法目录重复说明。

## 常见方案

| 方法 | 特点 |
| --- | --- |
| HNSW | 高召回、低延迟，但内存和构建成本较高 |
| IVF | 通过探测簇数调节速度与召回 |
| PQ/OPQ | 压缩内存，需要评估量化损失 |
| FAISS/ScaNN | 提供成熟的 CPU/GPU 大规模向量检索能力 |

## 生命周期

1. 固化模型版本、向量维度、归一化方式和距离函数。
2. 导出物品向量并检查缺失、NaN、范数和重复 ID。
3. 以精确 Top-K 为真值绘制召回率、时延和内存曲线。
4. 构建版本化索引，进行影子验证、预热和原子切换。
5. 通过增量索引接入新品，并定期全量重建。
6. 监控空结果率、过滤率、索引年龄、P95/P99 和资源占用。
