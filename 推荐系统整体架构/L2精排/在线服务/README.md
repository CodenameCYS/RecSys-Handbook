# L2 精排：在线服务

在线服务将 L1 候选、请求时刻特征、L2 模型、校准器和效用配置组织为有 deadline 的候选级决策链路。它的目标不是单纯降低推理延迟，而是在正确性、P99、可靠性、成本和端到端价值之间保持可验证的平衡。

完整的问题定义、评测维度、方法边界和验证顺序见[在线服务综述](./在线服务综述.md)。本目录只讨论 L2 的候选级服务；列表约束、频控、合规和供给决策仍归 L3。

## 专题导航

| 专题 | 主要问题 | 代表方法 |
| --- | --- | --- |
| [特征服务](./特征服务/README.md) | 线上特征是否在正确时刻可得且与训练一致 | schema、KV/缓存、TTL、默认值、point-in-time、序列窗口 |
| [推理优化](./推理优化/README.md) | 如何在效果与 P99/成本间取舍 | 批量化、并行、量化、编译、蒸馏、缓存、截断 |
| [级联与降级](./级联与降级/README.md) | 异常和高峰下如何保持候选决策语义 | 两阶段精排、轻量模型、版本化稳定融合分、熔断、回退 |
| [模型发布与监控](./模型发布与监控/README.md) | 如何安全变更并定位线上回归 | 联合制品发布、回放、Shadow、灰度、实验、回滚、观测 |
