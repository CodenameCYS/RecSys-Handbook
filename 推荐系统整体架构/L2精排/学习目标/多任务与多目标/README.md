# 多任务与多目标

精排往往同时关心 CTR、CVR、有效消费、价值和负反馈。多任务学习通过共享表示或共享专家，让稀疏任务利用相关任务的信号；多目标决策则把多个预测结果转化为最终排序效用。二者相关但不是同一件事：前者决定如何训练，后者决定如何排序与施加业务约束。

本页讨论任务定义、共享结构与冲突治理。各标签的样本空间、窗口与成熟度见[数据与特征：标签定义与时间窗口](../../数据与特征/标签定义与时间窗口/README.md)；概率进入排序前的可比性见[概率校准](../概率校准/README.md)。

## 1. 任务契约与漏斗关系

每个任务都应明确观察对象和条件。例如 CTR 通常定义在有效曝光上，CVR 定义在点击或意图样本上，负反馈则定义在曝光或消费后。不能因为它们共享用户和物品，就假设它们共享相同的负例。

| 任务 | 观察对象 | 典型输出 | 与其他任务的关系 |
| --- | --- | --- | --- |
| CTR | 有效曝光 | $P(click\mid exposure)$ | 漏斗上游 |
| CVR | 点击或意图样本 | $P(convert\mid click)$ | 漏斗下游、样本更稀疏 |
| CTCVR | 曝光样本 | $P(click\cap convert\mid exposure)$ | 可由 CTR 与 CVR 连接 |
| 有效消费 | 曝光或点击样本 | 消费概率/时长 | 质量维度，不等同点击 |
| 负反馈 | 有效曝光或消费样本 | 风险概率 | 排序护栏或独立目标 |

对点击后转化漏斗，常用关系为：

$$
P(CTCVR)=P(CTR)P(CVR)
$$

ESMM 在曝光空间同时学习 CTR 与 CTCVR，再由二者间接约束 CVR，可缓解只用点击样本训练 CVR 的选择偏差。它不消除标签延迟、曝光偏差或点击后样本本身的偏差。

## 2. 损失组合与权重语义

基本多任务损失为：

$$
\mathcal L=\sum_{k=1}^{K}\lambda_k\mathcal L_k
$$

$\lambda_k$ 同时表达业务优先级、标签规模、损失尺度和训练稳定性。固定权重适合任务稳定且已经过验证的基线；不确定性加权、GradNorm 或随训练阶段调度可缓解尺度失衡，但不应替代任务定义审计。

| 权重问题 | 可观察症状 | 优先处理 |
| --- | --- | --- |
| CTR 梯度压制稀疏 CVR | CVR 头长期无提升或退化 | 标准化损失、增大稀疏任务权重、检查标签质量 |
| 负反馈任务被忽略 | 点击升高但投诉/屏蔽上升 | 设置护栏权重或单独约束 |
| 任务量纲不一致 | 某任务损失数值主导总损失 | 检查标签和损失尺度，再考虑动态权重 |
| 权重频繁震荡 | 训练不稳定、分群结果反复 | 降低更新频率、固定基线并排查数据漂移 |

权重、采样、标签版本和模型结构都应写入实验契约；只报告总损失无法解释某个目标为何变好或变差。

## 3. 共享结构与任务冲突

| 结构 | 共享方式 | 适用场景 | 主要风险 |
| --- | --- | --- | --- |
| Shared-bottom | 共享底座 + 独立塔 | 任务高度相关、快速基线 | 负迁移和梯度冲突 |
| MMoE | 多专家 + 任务门控 | 相关性因人群/场景而变 | 专家塌缩、计算增加 |
| PLE | 共享与任务特有专家分离 | 任务差异明显且需减少干扰 | 结构更复杂、需监控门控 |
| 独立模型 | 不共享参数 | 任务冲突强、监管边界不同 | 不能共享稀疏信号、成本更高 |

梯度余弦相似度、任务头分群表现、专家门控分布与各任务的训练曲线可用于诊断冲突。若任务在业务上本就冲突，例如最大化即时点击与抑制重复曝光，不应期待仅靠共享结构自动解决，应在效用函数或 L3 约束中明确取舍。

## 4. 从多任务预测到多目标排序

多任务头输出后，仍需定义排序效用，例如：

$$
U=w_c\hat p_{click}+w_v\hat p_{convert}\hat v-w_n\hat p_{negative}
$$

其中各概率应在相同或可比的分布下校准，价值 $\hat v$ 的变换和截断也应可回放。权重 $w_c,w_v,w_n$ 属于决策层配置，不宜隐式写进标签或训练损失后失去可解释性。对硬性合规、库存和频控约束，通常交由 L3 后处理而不是指望效用权重“足够大”。

## 5. 评测与发布检查

1. 分别报告每个任务的 AUC/PR-AUC、LogLoss、校准和关键分群指标，而非只报告总损失。
2. 检查 CTR、CVR、负反馈等任务的样本空间、成熟度和采样规则是否一致且可追溯。
3. 监控梯度规模、任务梯度相似度、专家利用率和任务头预测分布，定位负迁移。
4. 离线模拟多目标效用时固定校准器、价值变换和权重版本；对权重做敏感性分析。
5. 线上实验同时设置主指标、护栏指标和长期观察窗口，避免短期 CTR 掩盖价值或风险恶化。

## 常见误解

- **共享底座自然提升所有任务**：任务关系、样本空间和梯度方向共同影响迁移效果。
- **任务权重只由业务优先级决定**：标签规模、损失量纲和训练稳定性同样需要纳入设计。
- **多任务输出相乘或相加就可排序**：概率校准、价值变换和约束归属必须先明确。
- **ESMM 解决了所有 CVR 偏差**：它处理特定漏斗选择问题，不能替代成熟标签和曝光审计。
