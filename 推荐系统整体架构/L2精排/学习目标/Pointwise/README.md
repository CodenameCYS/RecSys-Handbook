# Pointwise

Pointwise 将每个“请求 - 候选”样本独立映射为一个目标值，适合预测点击、转化、负反馈或质量标签等可定义为单样本监督信号的任务。它解决的是“该候选发生目标行为的条件概率或条件风险是多少”，而不是直接约束同一请求内的相对顺序。

本页说明 Pointwise 的样本前提、损失函数和概率解释。请求候选与曝光事实见[数据与特征：样本空间与曝光归因](../../数据与特征/样本空间与曝光归因/README.md)，标签窗口见[标签定义与时间窗口](../../数据与特征/标签定义与时间窗口/README.md)，概率用于融合前的校准见[概率校准](../概率校准/README.md)。

## 1. 样本与输出契约

对样本 $(x,i,y)$，$x$ 包含请求、用户、上下文与可用特征，$i$ 是候选，$y$ 是在固定曝光口径和成熟窗口下生成的标签。模型输出 logit $s(x,i)$，二分类任务的概率为：

$$
\hat p(x,i)=\sigma(s(x,i))=\frac{1}{1+e^{-s(x,i)}}
$$

| 任务 | 典型正例 | 合理样本空间 | 输出解释 |
| --- | --- | --- | --- |
| CTR | 有效曝光后点击 | 渲染或视口曝光 | 条件点击概率 |
| CVR | 点击或意图后转化 | 点击/意图条件样本 | 条件转化概率 |
| 负反馈 | 曝光后主动屏蔽等 | 有效曝光或消费样本 | 条件风险概率 |
| 质量分类 | 通过审核、有效消费等 | 明确业务对象 | 目标事件概率 |

Pointwise 的独立性不代表样本可随意拼接。CTR 不能把未曝光物品直接标为负，CVR 不能把未点击曝光等同于“点击后未转化”，而未成熟的延迟标签也不能直接写为零。

## 2. 二元交叉熵与加权损失

CTR 最常用二元交叉熵（BCE）为：

$$
\mathcal L_{BCE}=-y\log\hat p-(1-y)\log(1-\hat p)
$$

若业务需要调整类别影响，可使用类别权重：

$$
\mathcal L_{weighted}=-w_+y\log\hat p-w_-(1-y)\log(1-\hat p)
$$

权重会改变最优输出对应的训练分布，不能在未说明权重和采样方案时把输出直接解释为自然发生概率。若线上需要概率参与出价、价值计算或多任务融合，通常应在时间靠后的独立集上重新校准。

## 3. 类别不平衡与 Focal Loss

当有效曝光负例远多于正例时，Focal Loss 可以压低易分类样本的梯度：

$$
\mathcal L_{focal}=-\alpha_t(1-p_t)^\gamma\log(p_t)
$$

其中 $p_t$ 是真实类别对应的预测概率，$\gamma$ 控制对易样本的降权程度。它适合极度不平衡或需要突出难例的任务，但也更容易放大假负例和标注噪声。使用前应先检查曝光口径、成熟窗口和负样本来源；使用后应单独报告校准误差，而不是只比较 AUC。

## 4. 与排序目标的关系

Pointwise 不显式优化 $s(i^+)>s(i^-)$，但可通过候选特征、样本权重和线上效用函数间接服务排序。它通常是以下场景的稳健基线：

| 需求 | Pointwise 的作用 | 需要搭配的检查 |
| --- | --- | --- |
| 需要 CTR/CVR 概率 | 提供可解释的任务头 | LogLoss、Brier、ECE 与分群校准 |
| 多任务漏斗 | 作为共享底座上的独立任务损失 | 任务样本空间与梯度冲突 |
| Top-K 顺序不佳 | 提供概率信号或辅助损失 | Pairwise/Listwise 与请求内 NDCG |
| 跨目标效用融合 | 提供各行为的概率输入 | 校准、量纲和融合函数版本 |

若主要痛点是同请求中相近候选的前 K 次序，应将 Pointwise 与[Pairwise](../Pairwise/README.md)或[Listwise](../Listwise/README.md)目标比较，而不是仅靠增加网络复杂度。

## 5. 训练与评测检查

1. 固定曝光口径、负例来源、标签成熟截止时间和采样概率。
2. 训练、验证、测试按时间切分；统计量、词表和难例生成不能使用测试期信息。
3. 同时报告 AUC/PR-AUC、LogLoss、Brier、ECE 与请求、位置、场景等切片指标。
4. 记录类别权重、Focal 参数和采样版本，避免把训练分布变化误判为模型改进。
5. 对需要参与效用融合的头，使用独立时间集校准，并在线监控预测分布与真实频率。

## 常见误解

- **Pointwise 只能用于 CTR**：点击、转化、负反馈与二值质量标签均可定义为单点任务。
- **BCE 最小化后概率天然可直接融合**：仍需检查时间外校准和场景分布差异。
- **样本独立就不需要请求信息**：请求、位置和候选来源决定标签的条件语义。
- **类别加权与负采样不影响概率解释**：它们改变训练分布，应记录并在需要时校准。
