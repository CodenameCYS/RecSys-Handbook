# 概率校准

排序分数能把正例排在负例前，不代表它的数值就是可信概率。若 L2 输出会用于出价、跨任务效用融合、风险阈值或资源分配，预测为 $0.2$ 应当在相近样本中接近 20% 的真实发生频率；这就是校准问题。

本页讨论概率校准而非排序损失。Pointwise 输出与概率语义见[Pointwise](../Pointwise/README.md)，多任务输出如何进入效用函数见[多任务与多目标](../多任务与多目标/README.md)，ECE 等离线定义可参照[精排系统评测](../../精排系统评测.md)。

## 1. 什么是校准

令模型概率预测为 $\hat p$。理想校准满足：

$$
P(y=1\mid \hat p=p)=p
$$

实际中将预测分为 $M$ 个桶 $B_m$，每桶的平均预测与真实频率分别为：

$$
\operatorname{conf}(B_m)=\frac{1}{|B_m|}\sum_{i\in B_m}\hat p_i,
\qquad
\operatorname{acc}(B_m)=\frac{1}{|B_m|}\sum_{i\in B_m}y_i
$$

期望校准误差（ECE）为：

$$
\operatorname{ECE}=\sum_{m=1}^{M}\frac{|B_m|}{N}
\left|\operatorname{acc}(B_m)-\operatorname{conf}(B_m)\right|
$$

AUC 衡量相对顺序，LogLoss 衡量概率分配，Brier 衡量平方概率误差，ECE 反映分桶频率偏差。它们应共同报告：低 ECE 不代表排序好，高 AUC 也不代表概率可用于价值计算。

## 2. 校准数据与发布边界

校准器应在训练集之后、测试集之前的独立且时间更靠后的校准集上拟合。训练模型和拟合校准器共用同一数据，会低估真实时间外误差；把测试集用于选校准方法，则会污染最终评测。

```mermaid
flowchart LR
	A[训练时间段] --> B[训练模型]
	C[独立校准时间段] --> D[拟合校准器]
	B --> D
	D --> E[更晚测试/线上流量]
```

校准集与线上服务需保持相同的标签口径、成熟规则、候选层级和预测输入。若模型只对有效曝光校准，却把输出用在全候选集，校准结论不再成立。

## 3. 常见校准方法

| 方法 | 形式 | 适用情况 | 主要风险 |
| --- | --- | --- | --- |
| Platt scaling | $\sigma(a s+b)$ | 数据量有限、单调关系近似 logistic | 表达能力有限，分布变动时漂移 |
| Temperature scaling | $\sigma(s/T)$ | logit 尺度偏移、参数需简洁 | 只能整体缩放，难处理复杂失真 |
| Isotonic regression | 单调非参数映射 | 校准集充足、失真形状复杂 | 小样本易过拟合、分段跳变 |
| Beta/分段校准 | 更灵活的概率映射 | 二分类概率端点失真明显 | 实现与监控复杂度更高 |
| 分群校准 | 按场景/人群使用独立映射 | 分群基准率差异稳定 | 样本稀释、线上路由出错 |

选择方法时先比较未校准基线、总体和分群的 LogLoss、Brier、ECE 与可靠性曲线，再决定复杂度。校准器不应试图修复错误标签、位置偏差或训练服务特征漂移。

## 4. 分群校准与样本量

全局校准良好时，热门物品、冷启动物品、新用户或特定入口仍可能显著失准。常见切片包括场景、位置、用户活跃度、物品年龄、候选通道和设备。分群校准只有在每个群体具有足够成熟样本、线上路由稳定、增益超过复杂度时才值得使用。

| 现象 | 可能原因 | 优先动作 |
| --- | --- | --- |
| 总体 ECE 低但新品高估 | 物品年龄分布不同 | 增加年龄切片，检查训练覆盖 |
| 特定场景系统性低估 | 基准率或曝光口径不同 | 核对标签与候选层级，再考虑分场景校准 |
| 校准后 AUC 改变明显 | 映射非单调或实现错误 | 检查映射单调性与输入是否为同一分数 |
| 小群校准曲线剧烈波动 | 样本不足或标签未成熟 | 合并群体、正则化或延后发布 |

## 5. 监控与回滚

校准器与模型、特征 schema、标签口径和效用融合函数共同构成线上决策版本。模型重训、采样策略变化、场景流量变化或标签规则更新后，都应重新评估校准，不应只替换模型权重。

1. 在线监控整体及关键切片的预测分布、真实频率、LogLoss、Brier、ECE 和可靠性曲线。
2. 固定分桶策略或同时报告等宽、等频分桶，避免仅靠分桶选择掩盖失准。
3. 将校准器参数、训练时间窗、输入分数类型和版本一起发布，支持请求级回放。
4. 灰度比较未校准、旧校准和新校准的效用、护栏与数值稳定性，保留快速回滚路径。
5. 校准恶化时，先检查标签成熟度、特征/候选分布和服务一致性，再决定重新拟合或更换方法。

## 常见误解

- **AUC 高就代表概率可信**：AUC 衡量相对顺序，校准衡量预测概率与实际频率的一致性。
- **校准器是离线后处理细节**：校准器参与线上效用计算，需要随模型和特征版本共同发布。
- **校准能修复展示偏差和错误标签**：校准只调整预测映射，不能替代数据口径和偏差治理。
- **分群越细校准越准确**：小群样本不足时，独立校准器更容易过拟合和漂移。
