# L2 精排

L2 精排位于 L1 召回与 L3 后处理之间。它面向 L1 给出的有限候选集合，结合用户、物品、上下文、行为序列和召回来源等丰富特征，估计每个 `user-item-context` 对的行为概率与预期价值。

典型精排系统同时预估点击、转化、时长、收藏、负反馈和长期价值等信号，并将校准后的预估值融合为逐物品效用分。L3 在此基础上生成兼顾用户体验、业务目标与平台规则的最终列表。

## 模块边界

| 阶段 | 核心问题 | 输入 | 输出 |
| --- | --- | --- | --- |
| L1 召回 | 哪些物品进入候选竞争 | 全库 Index 与请求 | 多路候选及来源 |
| L2 精排 | 当前用户对每个候选的预期价值是多少 | L1 候选与丰富特征 | 多任务预估值、校准值、综合效用 |
| L3 后处理 | 最终列表如何兼顾体验与业务目标 | L2 分数、属性和规则 | 可直接曝光的有序列表 |
