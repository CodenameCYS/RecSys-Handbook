# BST

BST（Behavior Sequence Transformer）将用户历史作为 Transformer token 序列，通常加入位置、时间间隔、行为类型及候选交叉特征。适合顺序与上下文意图强的推荐场景。

序列长度决定注意力成本；应使用时间切分、因果 mask（若任务需要）和统一截断策略。与 DIN 比较时重点观察长序列、短序列、冷用户和 P99，而非只比较总体 AUC。

## 常见误解

- **Transformer 必然比注意力池化更强**：序列长度、顺序信号和服务预算决定合适结构。
- **双向上下文总能在线使用**：线上请求可用的行为范围决定 mask 与编码方式。
