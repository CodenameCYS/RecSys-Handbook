# DIN

DIN 用当前候选作为 query，对用户历史逐条计算 $[e_h,e_t,e_h-e_t,e_h\odot e_t]$ 注意力，得到候选相关兴趣表示。适合历史丰富且候选差异显著的场景。

需明确 padding mask、序列截断、行为时间顺序与空历史回退；多候选请求中其注意力计算随候选数和历史长度增长。本目录包含最小可运行的 [model.py](./model.py) 与 [train.py](./train.py) 样板。

## 常见误解

- **DIN 只要输入历史序列就能提升效果**：历史行为质量、候选相关性和序列截断共同决定收益。
- **注意力权重可直接解释用户意图**：权重是预测模型的内部机制，需要结合实验和业务语义分析。
