# DeepFM

DeepFM 联合一阶线性项、FM 二阶交叉与深层非线性项，适合多离散字段的 CTR 基线。FM 以 $\frac12[(\sum v)^2-\sum v^2]$ 高效计算二阶交互，DNN 补充高阶组合。

使用前确认字段词表、连续特征处理、多值池化、缺失/OOV 和训练服务一致。本目录包含最小可运行的 [model.py](./model.py) 与 [train.py](./train.py) 样板。

## 常见误解

- **DeepFM 自动完成全部特征工程**：词表、连续值、多值特征和缺失语义仍需显式设计。
- **FM 项覆盖高阶交叉**：FM 主要表达二阶交互，高阶关系由深层分支学习。
