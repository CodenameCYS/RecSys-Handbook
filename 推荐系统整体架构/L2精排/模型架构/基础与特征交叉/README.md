# 基础与特征交叉

本子模块处理 L2 最基础的问题：如何把离散字段、连续数值、多值特征和 L1 来源信号编码为可学习表示，并建模字段之间的显式或隐式交互。它通常是精排的第一层表征主干，也是用户兴趣、序列、多任务与多场景结构的共同基础。

进入本模块前，应先固定字段定义、词表/OOV、数值归一化、缺失语义和请求时刻特征快照。特征合同与离在线一致性见[数据与特征：特征工程与训练服务一致性](../../数据与特征/特征工程与训练服务一致性/README.md)。

## 模型能力与代价对比

| 模型族 | 主要优势 | 主要限制 | 服务侧关注点 |
| --- | --- | --- | --- |
| LR | 延迟低、解释直接、问题定位容易 | 依赖人工分桶和交叉，泛化有限 | 词表、哈希冲突、稀疏交叉覆盖 |
| Wide & Deep | 同时保留记忆规则与 embedding 泛化 | Wide 部分仍有人工维护成本 | 人工交叉定义与在线一致性 |
| DeepFM | 无需手工指定二阶交叉，工程成熟 | 交互机制较固定，对复杂字段选择未必充分 | embedding 表规模、多值池化、DNN 成本 |
| DCNv2 | 显式交叉阶数可控，能增强复杂交互 | 层数、低秩维度和专家数需消融 | 参数量、交叉层推理开销、P99 |
| AutoInt/FiBiNET | 可按样本选择字段关系或重标定字段重要性 | 注意力不等于因果解释，计算更重 | 字段数增长下的注意力成本与缺失稳定性 |

## 选择路径

1. 以 LR 或轻量 MLP/Wide & Deep 打通样本、特征、校准与服务基线。
2. 若二阶稀疏交叉维护成本高，先比较 DeepFM 与现有基线。
3. 若固定二阶交互不足，且离线消融显示显式交叉有效，再尝试 DCNv2。
4. 若收益集中在不同字段组合或复杂字段依赖，再评估 AutoInt/FiBiNET；保持 embedding 宽度、字段集合、损失和训练预算一致。

字段交叉无法替代候选感知兴趣或行为顺序建模：历史行为是否与当前候选相关，应进入[用户兴趣建模](../用户兴趣建模/README.md)或[序列建模](../序列建模/README.md)判断。

## 评测与实施检查

- 固定候选、标签版本、负采样、特征 schema、embedding 总参数量与训练预算，再比较结构。
- 除 AUC 外报告 LogLoss、ECE、分场景/新老用户/冷热门物品指标，避免总体均值掩盖退化。
- 对显式交叉、注意力和字段重标定做消融，确认收益不是某个新特征或预处理变化导致。
- 线上观测特征缺失、OOV、embedding 查表失败、P99 和降级比例；复杂交叉不应突破请求预算。

## 常见误解

- **自动特征交叉可以替代特征治理**：词表、缺失、时间可用性和字段语义仍是所有模型的前提。
- **注意力或交叉权重就是业务因果贡献**：它们描述模型内部的预测机制，不能代替因果实验。
- **交叉层越深越好**：额外阶数同时增加过拟合和服务成本，应由消融与线上收益决定。
