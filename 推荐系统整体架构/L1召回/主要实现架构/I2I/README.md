# I2I 召回

## 核心思路

I2I 根据用户最近交互的种子物品扩展相似物品。统计式 I2I 将同一会话或时间窗口内的物品视为共现，并使用余弦相似度、Jaccard 或 lift 抑制单纯由热门度造成的共现。

## 数据构造

- 会话切分：按用户、时间间隔和业务场景切分行为序列。
- 共现窗口：窗口越小越强调局部意图，越大越强调长期关联。
- 权重：可按位置距离、时间间隔、用户活跃度和行为类型衰减。
- 统计式 I2I 不需要显式负例；Item2Vec 或对比学习版本需要负采样。

## 典型实现

示例统计每个物品的出现次数 $N(i)$ 与共现次数 $C(i,j)$，采用：

$$
sim(i,j)=\frac{C(i,j)}{\sqrt{N(i)N(j)}}
$$

## 文件与运行

- [model.py](./model.py)：会话共现拟合与 Top-K 近邻查询。
- [train.py](./train.py)：拟合小型会话数据并展示多种子融合。

仅依赖 Python 标准库，执行 `python train.py`。

## 部署方式

离线输出 `种子物品 -> [(候选物品, 相似度)]` 近邻表并写入 KV。线上根据近期种子读取、衰减、合并和过滤。Embedding 版本也可以接入 ANN，但并非所有 I2I 都需要 ANN。

## 局限与扩展

共现容易放大热门物品，且缺少用户条件。后续可扩展 Item2Vec、方向性转移、实时会话图、意图条件 I2I 和多模态相似度。
