# 向量 I2I 召回

向量 I2I 召回先通过行为、内容、图、序列或监督信号学习 item embedding，再使用余弦相似度、内积或距离函数查找近邻。物品向量通常离线导出，并通过 ANN 索引或离线全量计算生成 `item_id -> Top-N neighbors`。

## 内容导航

- [I2I 原生表示学习](./I2I原生表示学习/README.md)：训练样本和目标直接定义希望保留的 item-to-item 关系。
- [上游任务派生表示](./上游任务派生表示/README.md)：从 user-item 匹配、图推荐或序列预测任务中导出 item embedding，再将其复用于 I2I。
- [表示增强与迁移](./表示增强与迁移/README.md)：使用多模态特征、预训练模型或知识蒸馏增强原生表示或派生表示。

## 组织逻辑

向量方法不能只按模型名称平铺，因为 item embedding 与 I2I 目标之间存在不同关系：有些模型直接学习物品邻近关系，有些模型首先服务其他推荐任务，I2I 只是复用其中间产物；多模态和蒸馏则是可横向叠加的增强机制。这三类不是互斥的算法标签，而是用于说明表示的主要来源和训练责任。例如多模态 encoder 可以用 InfoNCE 直接训练，也可以蒸馏序列推荐模型。
