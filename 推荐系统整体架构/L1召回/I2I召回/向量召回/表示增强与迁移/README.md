# 表示增强与迁移

本目录收录能够增强 I2I 表示来源或迁移高成本模型能力的横向机制。它们可以与原生表示学习或上游任务派生表示组合，而不是一种互斥的基础训练目标。

## 内容导航

- [多模态与蒸馏](./多模态与蒸馏/README.md)：融合文本、图像、音频、视频和结构化属性，或将教师模型的分数与表示迁移到轻量 item encoder。

## 分类边界

多模态描述输入和表示来源，蒸馏描述知识迁移机制，两者并不天然属于同一种训练任务。将其放在同一增强模块，是因为它们都可以叠加到 Item2Vec、度量学习、图或序列模型之上，并最终产出适合离线导出和近邻检索的 item embedding。
