# 图表示学习

图表示学习将物品放入 user-item 二部图、item-item 共现图或异构图，通过随机游走、邻居聚合和排序目标学习节点 embedding。最终 item embedding 可建立 ANN 或预计算近邻表。

LightGCN 的完整推导与实现见[协同过滤/GraphCF](../../../../协同过滤/GraphCF/README.md)；本章关注图表示如何形成 I2I。

## 1. 图的选择

| 图结构 | 节点与边 | 学到的关系 |
| --- | --- | --- |
| user-item 二部图 | 用户、物品、交互边 | 多跳协同相似 |
| item-item 共现图 | 物品、会话共现边 | 局部共同消费 |
| 有向转移图 | 物品、先后顺序边 | 下一跳关系 |
| 异构图 | 用户、物品、品牌、作者、实体 | 多类型关系 |

边可以携带行为类型、时间、次数和置信度。不同关系不应无条件压成同一种无向边，否则替代、互补和顺序语义会混合。

## 2. 随机游走表示

DeepWalk/Node2Vec 类方法从图上采样节点序列，再使用 Skip-gram 训练：

$$
\max\sum_{v_t}\sum_{v_c\in window(v_t)}
\log P(v_c|v_t)
$$

Node2Vec 通过参数 $p,q$ 控制回访和向外探索，在局部同质性与结构角色之间权衡。PinSage 则使用重要性随机游走采样邻居，再执行图卷积，适合大规模 item 图。

随机游走把图转成序列，训练和 Item2Vec 相似，但上下文来自图路径而不只是原始用户 session。

## 3. 图神经网络

一般邻居聚合写为：

$$
h_v^{(k+1)}=
\operatorname{AGGREGATE}
\left(h_v^{(k)},
\{h_n^{(k)}:n\in N(v)\}\right)
$$

LightGCN 在 user-item 图上采用规范化线性传播：

$$
E^{(k+1)}=D^{-1/2}AD^{-1/2}E^{(k)}
$$

并平均各层表示。物品最终向量吸收直接用户邻居和多跳物品协同关系，可直接执行 cosine 或 inner-product ANN。

GraphSAGE、GAT 和 PinSage 可聚合节点内容特征，使表示具有一定归纳能力；纯 ID LightGCN 对图中不存在的新品仍无法直接编码。

## 4. 训练目标

图传播只定义 encoder，还需要目标函数：

- BPR：优化 user 对正物品高于负物品。
- Link prediction：判断一条边是否存在。
- Random-walk context：预测游走窗口节点。
- InfoNCE：将相连节点或图增强双视图作为正例。
- 多关系目标：按边类型预测替代、互补或知识关系。

GraphCF embedding 能用于 I2I，不代表训练目标直接优化了 item-item 近邻。应针对目标关系做独立评测。

## 5. 多跳传播的收益与风险

二跳传播连接共同用户的物品，三跳和更深层可引入更广泛协同信号。收益是覆盖没有直接共现的相关物品，风险包括：

- 热门节点将信息传播到大量物品。
- 深层表示过度平滑，物品向量趋同。
- 噪声边和曝光偏差沿图扩散。
- 全图传播提高训练和更新成本。

常使用边权归一化、时间衰减、关系分图、热门边下采样和较浅层数控制影响。

## 6. I2I 服务

训练结束后离线导出 item embeddings：

```text
图快照 -> 图模型训练 -> 最终节点传播
       -> item embeddings -> ANN/Top-N -> I2I 服务
```

在线不执行全图传播。图快照、模型、ID 映射、最终 embedding 和 ANN 必须同版本。频繁新增交互可以通过周期性增量图构建或局部更新吸收，但局部更新与全图传播结果不完全等价。

## 7. 评测

同时评估目标关系 Recall@K、用户下一次交互命中、覆盖率、热门度和多样性，并按节点度分桶。高阶图模型应与 ItemCF、MF-I2I 和内容向量比较增量价值，而不只与随机基线比较。

图表示适合多跳关系确有价值且图数据充足的场景；对于简单、稳定的局部共现，ItemCF 往往成本更低。
