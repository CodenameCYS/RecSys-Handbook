# 上游任务派生表示

本目录收录先为其他推荐目标学习 item embedding，再将该表示导出并复用于 I2I 的方法。典型流程是“训练上游任务 → 选择并导出 item embedding → 确定相似度函数 → 构建 ANN 索引或近邻表”。

这类用法更准确地称为表示复用或派生表示，而不是严格的迁移学习：它通常没有独立的 I2I 微调阶段，也未必涉及源域到目标域的参数适配。

## 内容导航

- [矩阵分解表示](./矩阵分解表示/README.md)：从评分重构、Weighted ALS 或 BPR 等 user-item 目标中导出物品因子。
- [图表示学习](./图表示学习/README.md)：从图传播、链路预测或图推荐目标中导出物品节点表示。
- [序列预测表示](./序列预测表示/README.md)：从下一物品预测或掩码物品预测模型中选择输入、输出或组合 embedding。

## 使用边界

上游任务效果提升并不保证 I2I 近邻质量同步提升。导出时需要单独验证 embedding 层选择、向量归一化、相似度函数、方向性以及近邻关系语义，并同时评测 item-item 关系和完整用户召回链路。
