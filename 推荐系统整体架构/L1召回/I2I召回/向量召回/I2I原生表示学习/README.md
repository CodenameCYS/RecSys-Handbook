# I2I 原生表示学习

本目录收录训练目标直接塑造 item-to-item 邻近关系的方法。它们从共现窗口、标注物品对、三元组或同一物品的增强视图构造训练样本，优化后的 embedding 可以直接用于 I2I 近邻检索。

## 内容导航

- [Item2Vec](./Item2Vec/README.md)：通过行为窗口中的中心物品与上下文物品预测学习共现关系。
- [监督度量学习](./监督度量学习/README.md)：通过物品对、三元组或关系标签直接定义目标距离。
- [InfoNCE](./InfoNCE/README.md)：将正例与一组负例共同归一化，学习可检索向量空间。
- [SimCSE-style](./SimCSE/README.md)：通过同一物品的随机双视图构造自监督一致性目标。

## 分类边界

判断标准不是模型是否还能服务其他任务，而是当前训练样本和优化目标是否直接表达预期的 I2I 关系。监督信号若来自教师模型，仍可在此训练 I2I encoder，但其知识来源同时涉及[表示增强与迁移](../表示增强与迁移/README.md)。
