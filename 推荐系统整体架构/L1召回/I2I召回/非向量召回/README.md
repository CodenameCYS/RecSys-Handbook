# 非向量 I2I 召回

非向量 I2I 召回不要求先把所有物品映射到统一的稠密向量空间，而是直接根据字段重合、稀疏文本得分、显式关系、规则或图路径计算物品间关系。离线系统通常将结果物化为 `item_id -> Top-N neighbors`，线上按种子物品查表并参与多种子融合。

## 内容导航

- [内容与属性相似度](./内容与属性相似度/README.md)：使用 TF-IDF、BM25、类目、标签和结构化属性构建可解释的相似关系。
- [知识与关系相似度](./知识与关系相似度/README.md)：使用实体边、业务关系、元路径和图遍历构建带类型或方向的关联关系。

## 分类边界

本目录的判断标准是关系能否由可解释字段或显式结构直接计算，而不是实现中是否出现“向量”数据结构。TF-IDF 即使以稀疏向量实现，核心仍是直接词项匹配；反之，若内容编码器或知识图模型学习出稠密 embedding 并通过 ANN 检索，则应归入[向量召回](../向量召回/README.md)。行为共现 ItemCF 也属于非向量关系，但其算法体系统一放在[协同过滤/ItemCF](../../协同过滤/ItemCF/README.md)中维护。
