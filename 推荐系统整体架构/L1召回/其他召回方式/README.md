# 其他召回方式

双塔、协同过滤、I2I 和生成式召回主要处理个性化相关性，但真实系统还必须应对无历史用户、新物品、突发热点、确定性业务供给和反馈不足等问题。本目录收录无法只靠个性化主模型稳定解决的补充召回通道。

这些通道按主要信号来源和业务职责划分，而不是按模型结构划分。例如内容召回可以使用双塔编码器，图召回也可以使用 ANN；将它们独立组织，是为了明确各自的数据生产、触发条件、候选责任和增量价值。整体关系见[其他召回方式综述](./其他召回方式综述.md)。

## 内容导航

- [其他召回方式综述](./其他召回方式综述.md)：比较五类补充通道的核心信号、职责和常见服务产物。
- [热门与趋势召回](./热门与趋势召回/README.md)：利用时间衰减后的曝光和反馈统计响应热点，并为低历史用户提供兜底。
- [内容检索召回](./内容检索召回/README.md)：通过文本、标签、类目或多模态内容覆盖新品和显式语义意图。
- [图与知识召回](./图与知识召回/README.md)：沿作者、主题、实体和业务关系执行多跳扩展，提供关系型候选。
- [规则与运营召回](./规则与运营召回/README.md)：注入活动、白名单、保量供给和确定性业务候选。
- [探索召回](./探索召回/README.md)：结合收益估计、不确定性和曝光预算，为新品与长尾物品收集反馈。

## 组织逻辑

五个子目录对应“时效信号、内容信号、关系信号、业务配置和不确定性”五种不同的信息来源。它们与个性化主召回并行运行，但不能使用同一套成功标准：热门通道关注时效和稳定性，内容通道关注冷启动覆盖，运营通道关注确定性约束，探索通道还必须记录曝光概率并控制试错成本。因此本目录按职责拆分，便于分别治理和评测。
