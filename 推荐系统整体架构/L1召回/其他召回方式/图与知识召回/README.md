# 图与知识召回

图召回把用户、物品、作者、商家、主题、社交关系和知识实体建成节点，把点击、关注、创作、属于、相似等关系建成边。它可以从用户或近期物品出发进行多跳扩展，发现仅靠局部共现难以覆盖的候选，并用路径提供一定解释。

## 1. 方法边界

图与知识召回的核心不是“使用了 GNN”，而是候选因一条或多条关系路径成立。它与相邻方法的边界是：

- UserCF、ItemCF 和 GraphCF 主要从交互图学习协同关系。
- I2I 主要从一个或多个种子物品扩展相似、替代或互补物品。
- 图与知识召回进一步使用作者、商家、主题、实体、社交和业务关系，并显式治理路径语义。
- 图 embedding 若只写入 ANN 做相似检索，在线形态是向量召回；若在线结果携带可信路径，则仍具有图召回职责。

图的优势是能表达“为什么相关”，局限是路径存在不代表用户一定喜欢，错误实体链接和高度节点还会放大噪声。

## 2. 图的类型与适用问题

| 图类型 | 节点与边 | 适合的问题 | 主要风险 |
| --- | --- | --- | --- |
| 用户-物品二部图 | 用户、物品、交互 | 协同扩展和潜在兴趣 | 热门偏差、缺少关系解释 |
| 会话图 | 物品及有向转移 | 当前 session 的短期意图 | 快速过期、噪声转移 |
| 社交图 | 用户、关注、好友 | 社交发现与信任传播 | 同温层、隐私和关系滥用 |
| 作者/商家图 | 作者、商家、内容、关注 | 同作者、新作和供给发现 | 头部供给垄断 |
| 知识图谱 | 物品、品牌、品类、演员、主题等实体 | 精确关系、跨域连接与解释 | 实体链接和关系质量 |
| 异构图 | 多种节点与带类型边 | 统一多源关系 | 关系混淆、采样与服务复杂 |

边应记录方向、类型、时间、权重和来源。旧行为需要衰减，异常账户和刷量边应先过滤。训练、离线评测和在线回放均需使用目标时点之前的图快照。

### 2.1 Schema 与边语义

上线前应先定义图 schema，而不是把所有关系写成无类型连边。示例：

```text
User -[follow]-> Author -[create]-> Item
Item -[belongs_to]-> Topic <-[belongs_to]- Item
Item -[has_brand]-> Brand <-[has_brand]- Item
User -[click, timestamp, dwell]-> Item
```

边权可综合行为强度、时间衰减和可信度：

$$
w_e=w_{type(e)}\cdot q_e\cdot
\exp\left(-\frac{t-t_e}{\tau_{type(e)}}\right)
$$

不同关系的时间尺度不同：关注关系可能长期有效，会话点击可能数十分钟后就应明显衰减。

## 3. 主要算法族

| 算法 | 核心思想 | 服务形式 |
| --- | --- | --- |
| 一跳邻居 | 从用户、物品或实体直接取相邻物品 | 在线邻接表或预计算 Top-K |
| 多跳扩展 | 按边权逐层展开并聚合路径 | 有界 BFS、beam expansion |
| Personalized PageRank | 随机游走并以概率 $\alpha$ 回到种子 | 预计算、近似 PPR 或在线小图 |
| Metapath | 限定 `用户-作者-物品` 等关系序列 | 路径模板、倒排和预计算 |
| 路径打分/推理 | 学习关系组合或路径可信度 | 候选路径模型、知识图推理 |
| 图 embedding/GNN | 聚合邻居学习节点表示 | 向量导出到 Index 池 |

### 3.1 邻居与多跳扩展

给定种子集合 $S$，一跳扩展直接读取邻接表。多跳扩展对路径 $p=(e_1,\ldots,e_L)$ 累积得分，例如：

$$
s(i)=\sum_{s\in S}\sum_{p:s\leadsto i}
w_s\cdot w_{type(p)}\cdot\prod_{e\in p}\widetilde w_e
$$

路径乘积会随长度快速衰减，有助于限制远距离噪声。生产系统通常只展开 1 到 3 跳，并为每层设置 fan-out、关系白名单和候选上限。

### 3.2 Personalized PageRank

PPR 迭代可写为 $p_{t+1}=\alpha p_0+(1-\alpha)P^Tp_t$。重启项保留个性化种子，传播项探索关系图。异构图中不能让高出度节点天然垄断，应做边类型配额、度归一化和时间衰减。

精确 PPR 在大图上成本高，常用近似 push、Monte Carlo、按用户/实体预计算，或只在请求相关的小子图中运行。$\alpha$ 越大越靠近种子，越小越容易发现远端候选，也越容易退化为全局热门。

### 3.3 Metapath

Metapath 显式限定关系序列，例如：

- `User -> follows -> Author -> creates -> Item`：关注作者的新内容。
- `Item -> actor -> Actor -> acts_in -> Item`：同演员作品。
- `Item -> accessory_type -> Type -> compatible_with -> Item`：互补配件。

不同路径表达不同业务含义，不能简单混为“图距离两跳”。路径权重可以规则设定，也可以由下游点击和消费数据学习。

### 3.4 图表示学习

DeepWalk、node2vec、LightGCN 和异构 GNN 可把图结构压缩为 embedding，再通过 ANN 检索。它们适合大规模、低延迟服务，但会丢失部分显式路径信息。训练时要使用时间快照、控制邻居采样，并防止测试期边泄漏到 embedding。

## 4. 种子构造与候选打分

种子可以是用户节点、最近消费物品、关注作者、显式实体或多个兴趣簇。多种种子应按行为和时间加权：

$$
w_s=w_{behavior(s)}\exp\left(-\frac{t-t_s}{\tau}\right)
$$

误触和过时种子会沿图放大，因此需要负反馈降权、已看过滤和兴趣分簇。候选聚合时既要保留总分，也要保留主要种子和路径；后者用于解释、调试、去重和下游特征。

## 5. 在线与离线服务形态

### 5.1 离线物化

对高频用户、物品、作者或实体预计算 Top-K 图候选，在线直接查 KV。它延迟稳定，适合静态知识关系和高频路径，但实时性受刷新周期限制。

### 5.2 在线有界扩展

请求时读取邻接表并执行有界 BFS、beam 或局部 PPR。适合会话图和强实时关系，但必须限制：

- 最大跳数与每层 fan-out。
- 允许的节点和边类型。
- 单个高度节点贡献上限。
- 总访问节点、候选数量和 deadline。

### 5.3 混合服务

静态知识图和高频路径离线物化，实时关注、会话边叠加在线增量层。服务输出至少包含 `item_id、score、seed、path_type、graph_version`，并在超时或图版本异常时回退到预计算结果。

## 6. 知识图谱质量

知识召回的上限由实体和关系质量决定：

- 实体消歧：同名人物、品牌和地点是否链接正确。
- 实体归一：别名、语言和版本是否合并。
- 关系可信度：来源是否可靠，是否有生效和失效时间。
- 覆盖与新鲜度：新物品是否及时链接，旧关系是否删除。
- 反向边语义：`作者创作物品` 的反向可成立，但不是所有关系都可对称。

错误边会系统性召回错误候选，不能只靠排序模型兜底。高风险关系应设置来源白名单和人工抽检。

## 7. 在线治理

控制最大跳数、每层 fan-out、允许的边类型、节点黑白名单和总扩展预算。高频路径可离线物化，实时会话边可叠加在静态图上。候选需携带主要路径或种子贡献，用于解释、去偏和问题定位。

监控节点/边覆盖率、图快照年龄、孤立节点率、度分布、每跳候选膨胀、路径类型占比、热门节点集中度、查询 P99、独占候选率和增量 Recall。知识图还要监控实体链接准确率和关系版本。

## 8. 适用场景与局限

适合：社交推荐、作者/商家关注、新作发现、同系列内容、知识实体关联、配件互补、跨域实体连接，以及需要可解释路径的候选发现。

局限：

- 图构建、实体链接和关系维护成本高。
- 高度节点会把结果推向热门，长路径会累积噪声。
- 关系相关不等于用户当前有消费意愿。
- 在线多跳访问容易造成尾延迟和候选爆炸。
- 社交图涉及隐私、安全和关系滥用风险。

## 9. 评测与常见误区

除 Recall@K、NDCG@K 和增量覆盖外，应按路径类型报告命中、L2 采用和最终曝光，抽检路径语义，测量每跳膨胀、孤立节点率、高度节点集中度、图新鲜度和 P99。

常见误区：

- **跳数越多发现越丰富**：远距离关系通常噪声更大，成本也快速增长。
- **有路径就可解释**：错误或弱语义路径只能制造虚假解释。
- **PPR 自动解决异构关系**：不区分边类型时，高频关系会吞没其他语义。
- **图 embedding 等于完整图召回**：向量便于服务，但未必保留关系类型和路径。
- **图快照可以随机切分评测**：未来边泄漏会显著高估效果。
