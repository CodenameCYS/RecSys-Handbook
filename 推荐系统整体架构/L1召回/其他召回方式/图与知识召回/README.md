# 图与知识召回

图召回把用户、物品、作者、商家、主题、社交关系和知识实体建成节点，把点击、关注、创作、属于、相似等关系建成边。它可以从用户或近期物品出发进行多跳扩展，发现仅靠局部共现难以覆盖的候选，并用路径提供一定解释。

## 1. 图的选择

- 用户-物品二部图：适合 LightGCN、随机游走和协同扩展。
- 会话图：节点是物品，边表示同一会话中的有向转移，强调短期意图。
- 社交/作者图：沿关注、共同好友、作者-内容关系发现候选。
- 知识图谱：沿品牌、品类、演员、主题等实体关系进行路径约束扩展。
- 异构图：统一多种节点和边，但必须区分关系语义与采样比例。

边应记录方向、类型、时间、权重和来源。旧行为需要衰减，异常账户和刷量边应先过滤。训练、离线评测和在线回放均需使用目标时点之前的图快照。

## 2. 主要算法

| 算法 | 核心思想 | 服务形式 |
| --- | --- | --- |
| 邻居/多跳扩展 | 按边权展开一到数跳并聚合路径 | 在线邻接表或预计算 Top-K |
| Personalized PageRank | 随机游走并以概率 $\alpha$ 回到种子 | 预计算、近似 PPR 或在线小图 |
| metapath | 限定 `用户-作者-物品` 等关系序列 | 路径模板与倒排表 |
| 图 embedding/GNN | 聚合邻居学习节点表示 | 向量导出到 Index 池 |

PPR 迭代可写为 $p_{t+1}=\alpha p_0+(1-\alpha)P^Tp_t$。重启项保留个性化种子，传播项探索关系图。异构图中不能让高出度节点天然垄断，应做边类型配额、度归一化和时间衰减。

## 3. 在线治理

控制最大跳数、每层 fan-out、允许的边类型、节点黑白名单和总扩展预算。高频路径可离线物化，实时会话边可叠加在静态图上。候选需携带主要路径或种子贡献，用于解释、去偏和问题定位。

监控节点/边覆盖率、图快照年龄、孤立节点率、度分布、每跳候选膨胀、路径类型占比、热门节点集中度、查询 P99、独占候选率和增量 Recall。知识图还要监控实体链接准确率和关系版本。
