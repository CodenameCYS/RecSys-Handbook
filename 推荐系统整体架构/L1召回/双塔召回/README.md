# 双塔召回

双塔召回分别编码请求侧与物品侧，将两侧映射到统一向量空间，并通过向量检索从大规模物品库中生成候选。它主要解决“如何在保留个性化匹配能力的同时，让物品表示可以离线预计算，从而满足大规模低延迟检索”的问题。

该模块围绕样本、表示学习和在线检索三部分展开：训练数据决定模型学习什么偏好，用户塔与物品塔决定如何表达请求和候选，匹配损失与 ANN 索引则把离线表示转化为线上 Top-K 结果。完整原理与工程链路见[双塔召回综述](./双塔召回综述.md)。

## 组织逻辑

双塔效果首先受样本定义约束，其次才是编码器结构，因此目录将“数据构造”和“模型架构”分开。模型架构下再以 MLP 和 Transformer 展示静态特征基线与序列兴趣建模两条常见路线；ANN 索引作为多种向量召回共享的基础设施，统一放在 [Index 池](../../Index池/README.md) 中说明。
