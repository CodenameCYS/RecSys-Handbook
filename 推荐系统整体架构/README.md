# 推荐系统整体架构

本目录介绍工业推荐系统从候选商品管理到最终推荐结果生成的完整在线链路。在线请求的主漏斗按照 **Index 池、L1 召回、L2 精排、L3 后处理** 四个主要模块组织；数据、实验、供给生态和长期策略通过反馈闭环跨越这些模块，而不是额外串行阶段。

## 文件架构

```text
推荐系统整体架构/
├── README.md
├── 推荐系统整体架构综述.md
├── Index池/
├── L1召回/
├── L2精排/
└── L3后处理/
```

## 模块说明

| 模块 | 主要内容 |
| --- | --- |
| [推荐系统整体架构综述](./推荐系统整体架构综述.md) | 介绍推荐系统的端到端框架、四阶段职责、模块接口、数据反馈闭环、部署方式和系统保障。 |
| [Index 池](./Index池/README.md) | 介绍可推荐商品池、准入与过滤、特征准备、索引构建、生命周期和版本管理。 |
| [L1 召回](./L1召回/README.md) | 介绍如何通过多路召回从大规模 Index 池中快速生成候选集合。 |
| [L2 精排](./L2精排/README.md) | 介绍如何使用用户、商品、上下文和行为特征对候选进行个性化打分。 |
| [L3 后处理](./L3后处理/README.md) | 介绍硬规则、去重、多样性、配额与编排如何生成最终展示序列，以及公平、探索和长期策略如何以跨请求状态注入当前列表求解。 |
