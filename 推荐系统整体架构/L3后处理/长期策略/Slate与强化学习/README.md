# Slate 与强化学习

Slate 决策与强化学习面向位置之间的替代、互补和延迟反馈，优化长期价值而非单次点击。Slate 将一个有序列表视为整体动作，适合表达首屏位置、相似内容互相蚕食、模块编排和列表多样性；强化学习（RL）进一步把用户状态演化和延迟回报纳入序列决策。

引入前应先验证反事实评估和安全离线训练的可信度，线上必须采用小流量灰度、明确回退策略和多维业务护栏。它不替代[基础规则与约束](../../基础规则与约束/README.md)：每一步动作都只能在可行候选中进行，并仍须满足去重、频控、库存、合规和页面位置规则。

## 1. 状态、动作与奖励

| 要素 | Slate 决策 | 强化学习扩展 |
| --- | --- | --- |
| 状态 $s$ | 请求上下文、候选、位置和已选前缀 | 再加入用户历史、疲劳、会话阶段与可持久状态。 |
| 动作 $a$ | 一个长度为 $K$ 的有序列表或逐位置选择 | 当前列表或下一步策略动作。 |
| 转移 | 单次请求后通常不显式建模 | $P(s_{t+1}\mid s_t,a_t)$，包括反馈、时间和外部变化。 |
| 奖励 | 展示、消费、满意度、负反馈的列表级组合 | $R_t$ 或折扣回报 $G_t=\sum_{j\ge0}\gamma^jR_{t+j}$。 |

奖励必须冻结定义、归因窗口与缺失标签处理。将 N 日留存直接归因给单次 slate 往往噪声很大；更稳妥的做法是先验证短期代理奖励与长期标签的关联，并在实验设计中保留对照。

## 2. 组合动作与日志要求

从 $N$ 个候选选择并排列 $K$ 个位置的动作数为 $N!/(N-K)!$。因此，枚举全量 slate、精确计算所有动作价值或把每个位置的独立动作概率相乘，都可能错误或无法满足请求 deadline。生产实现常采用逐位置条件策略、beam search、候选截断或[约束优化与编排](../../约束优化与编排/README.md)的联合求解；这些近似必须同时记录实际的选择过程和对应概率语义。

最小日志应包含候选集/截断规则、最终 slate 与位置、每步条件动作及其倾向或完整 slate 的概率、策略/模型版本、随机化版本、硬规则命中、输入状态快照和 `policy_mode`。若只能记录逐位置概率，离线评估必须使用与该因子分解一致的方法，不能把它误当作独立位置展示策略。

## 3. 离线训练、评测与发布

- 训练数据按曝光机会构造，保留未点击和负反馈；处理迟到、重复、策略漂移和 reward censoring。
- 反事实评估检查支持集重叠、propensity 校验、权重裁剪敏感性和置信区间。对长时序 RL，离线 OPE 的假设通常更强，应先在简单策略空间验证。
- 评估列表级效用、位置覆盖、多样性、长期代理、负反馈、用户/供给切片与硬约束零违规；平均回报不能掩盖安全或公平退化。
- 发布采用 shadow 评分、离线回放、小流量、逐级扩大和一键回退。模型、特征或奖励口径任一变化都应视为新策略版本。

## 4. 时延与故障语义

令 $N$ 为可行候选数、$K$ 为列表长度、$B$ 为 beam 宽度。逐位置贪心打分的典型成本约为 $O(NK)$；beam search 常为 $O(BNK)$，内存为 $O(BK)$ 加候选特征。精确组合求解不可直接作为通用在线默认值。

为策略评分、位置选择和约束收口分别设置预算。模型、状态或联合求解超时，或策略输出无有效 slate 时，立即回退到版本化的相关性重排/贪心编排；硬规则仍须执行。输出与日志中记录回退原因，反馈训练时不得将回退流量混入目标策略样本而不做标记。
