# 意图覆盖与 xQuAD

xQuAD（Explicit Query Aspect Diversification）将候选级效用与尚未覆盖的子意图收益结合。它适合系统能够在请求时提供用户意图分布、查询改写意图、类目偏好或主题证据的场景；与只使用候选间相似度的 MMR 相比，xQuAD 可以明确回答“这一位置在补足哪个意图”。

它是软目标重排，不应把低置信意图标签升级为展示资格，也不能绕过[基础规则与约束](../../基础规则与约束/README.md)。当意图标签无法稳定在线提供时，优先采用更可靠的 MMR 或相关性排序基线。

## 1. 目标函数与输入契约

令 $Z$ 为有限意图集合，$P(z\mid u,q)$ 为当前用户/请求的意图权重，$P(z\mid i)$ 为候选对意图的覆盖强度。对已选列表 $S$，一个常用 xQuAD 贪心分数为：

$$
score(i\mid S)=(1-\lambda)r_i+
\lambda\sum_{z\in Z}P(z\mid u,q)P(z\mid i)
\prod_{j\in S}(1-P(z\mid j)).
$$

乘积项表示意图 $z$ 尚未被已选项目覆盖的程度。$\lambda$ 控制候选效用与意图补全的权衡；它与 MMR 的参数含义相近，但不可直接迁移数值。

| 输入 | 作用 | 要求 |
| --- | --- | --- |
| `item_id`、`input_index` | 稳定选择和回放 | 同分有确定性 tie-break |
| `score` | L2 校准后的候选效用 | 分数版本与方向一致 |
| `intent_scores` | $P(z\mid i)$ 或可比较的覆盖强度 | 覆盖范围、归一化和缺失语义明确 |
| `intent_weights` | $P(z\mid u,q)$ | 请求时可用、可解释且版本化 |

## 2. 意图建模与标签质量

意图可以来自显式查询分类、类目/主题模型、会话行为、短期兴趣簇或运营定义。关键不是意图数越多越好，而是意图能够在请求时稳定获得，并且候选覆盖证据与用户实际感知相符。

| 意图来源 | 优势 | 风险与检查 |
| --- | --- | --- |
| 查询/会话分类 | 可贴近当次需求 | 改写、歧义和低置信请求需有回退 |
| 类目或主题标签 | 易解释、成本低 | 粒度过粗时会把合理同主题候选错误视为重复 |
| 用户兴趣簇 | 可利用长期偏好 | 可能压制当次短期意图，需与上下文权重融合 |
| 运营定义 | 可保证业务重点 | 不可将运营权重伪装成用户意图，应单独记录策略来源 |

对每一版标签，离线评估覆盖准确性、未知率、意图熵和线上可用率。低置信或缺失的意图分布应回退为 $\lambda=0$ 的相关性稳定排序，或使用经验证的默认分布，并记录回退原因。

## 4. 复杂度与请求时实现

令 $N$ 为候选数、$K$ 为目标列表长度、$m$ 为活跃意图数。xQuAD 的性能关键在于是否重复计算已选列表对每个意图的覆盖：

| 实现方式 | 请求时复杂度 | 增量空间 | 说明 |
| --- | --- | --- | --- |
| 朴素重算乘积项 | $O(NK^2m)$ | $O(1)$ | 每轮为每个候选、每个意图重新遍历已选集合；仅适合讲解或极小列表。 |
| 维护意图未覆盖度 | $O(NKm)$ | $O(m)$ | 选择新候选后只更新 $m$ 个未覆盖概率；推荐的在线基线。 |
| 稀疏意图实现 | $O(NK\bar m)$ | $O(m)$ | $\bar m$ 为每候选非零意图数；需保留缺失意图的明确语义。 |

候选意图特征本身的空间为稠密表示 $O(Nm)$，或稀疏表示 $O(N\bar m)$，常常比算法工作区更值得控制。线上应先截断低权重意图和低效用候选，避免为几乎没有用户价值的长尾意图扩大 $m$；不可为降低耗时而把未知意图当作已覆盖。

## 5. 服务、降级与评测

- 记录每个位置的 L2 效用、各意图未覆盖度、覆盖增益、$\lambda$、意图权重/标签版本、选择原因和回退路径。
- 将候选截断、意图分布读取、候选覆盖读取与重排分别计时；当剩余预算不足以完成下一轮时，使用相关性稳定顺序补齐未选位置。
- 意图服务超时、分布无效或候选覆盖全缺失时，回退到相关性稳定排序或已验证的 MMR；回退仍须遵守基础规则。
- 离线同时比较 NDCG/效用、意图覆盖率、加权覆盖增益、重复率与用户切片；线上观察点击/消费、任务完成、负反馈和意图标签缺失率。

## 常见误解

- **xQuAD 只需要类目标签**：类目是否能代表本次子意图需要通过请求级证据验证。
- **覆盖越平均越好**：用户意图权重不均时，强行平均覆盖会损伤主意图的相关性。
- **每个位置覆盖的意图都是用户真实意图**：它是模型与策略给出的证据，应与线上实验和诊断共同解释。
