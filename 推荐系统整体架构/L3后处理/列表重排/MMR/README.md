# MMR

Maximum Marginal Relevance（MMR）以贪心方式构建列表：每一步在剩余候选中选择 L2 效用较高、同时与已选集合不太相似的物品。它是列表重排中成本最低、最容易解释的相关性与冗余折中基线，适合候选数可控且相似度信号可信的场景。

MMR 只作用于已通过[基础规则与约束](../../基础规则与约束/README.md)的候选；库存、合规、频控和实体去重必须先定义可行集合，不能通过降低 MMR 分数来替代。

## 1. 目标函数与输入契约

第 $t$ 个位置的已选集合为 $S$，剩余候选为 $R$。MMR 选择：

$$
i^*=\arg\max_i\left[\lambda r_i-(1-\lambda)\max_{j\in S}sim(i,j)\right]
$$

$r_i$ 是经校准、方向一致的 L2 效用，$sim(i,j)$ 是候选间的相似度，通常应落在 $[0,1]$；$\lambda\in[0,1]$ 越大越偏向相关性，越小越强调差异。最小输入字段为：

| 字段 | 含义 | 要求 |
| --- | --- | --- |
| `item_id` | 候选稳定标识 | 用于日志、稳定排序和回放 |
| `score` | L2 候选级效用 | 分数方向和校准版本一致 |
| `vector` 或相似度接口 | 内容、主题或行为语义 | 零向量、缺失值和版本有明确定义 |
| `input_index` | 进入 L3 的稳定位置 | 同分时保证输出可复现 |

## 2. 相似度与参数选择

相似度可以来自内容标签重合、embedding 余弦、主题分布距离或共现关系。它必须与目标一致：用作者相似度会抑制创作者集中，用语义 embedding 会抑制主题重复，两者产生的列表行为不同，不能复用同一 $\lambda$ 而不重新评估。

| 信号 | 优势 | 风险 |
| --- | --- | --- |
| 标签/Jaccard | 可解释、成本低 | 标签稀疏或不一致时漏掉近重复 |
| Embedding 余弦 | 覆盖语义近似 | 向量漂移、冷启动和负相似度需要归一化策略 |
| 共现/行为关系 | 可贴近用户实际替代性 | 热门偏置与反馈回路会放大相似度 |

先在固定候选集合上扫描 $\lambda$，再按请求长度、用户兴趣集中度、类目和冷启动切片观察相关性损失与冗余下降。不要将全局最优参数直接用于每一个场景；可按场景或列表长度下发版本化参数。

## 4. 复杂度与请求时实现

令 $N$ 为候选数、$K$ 为目标列表长度、$d$ 为向量维度。复杂度取决于是否重复计算已选相似度：

| 实现方式 | 请求时复杂度 | 增量空间 | 说明 |
| --- | --- | --- | --- |
| 朴素逐项扫描 | $O(NK^2d)$ | $O(1)$ | 每次为每个剩余候选重新计算与 $S$ 的最大相似度；仅适合教学/极小候选池。 |
| 维护最大相似度 | $O(NKd)$ | $O(N)$ | 每选一个候选，只更新所有剩余候选与新项的相似度；推荐的在线基线。 |
| 预计算相似度矩阵 | 构造 $O(N^2d)$，选择 $O(NK)$ | $O(N^2)$ | 仅当 $N$ 很小、核可复用且内存预算明确时使用。 |

向量特征本身通常占 $O(Nd)$，因此即使使用 $O(N)$ 的算法工作区，也必须限制进入重排的 $N$ 与 $d$。生产实现应维护 `max_similarity[item]`，而不是沿用本页样例的朴素扫描；样例保留朴素写法是为了直观呈现公式。

## 5. 服务、降级与评测

- 记录每个位置的 L2 效用、最大相似度、MMR 分、$\lambda$、相似度特征版本、输入位置与最终选择原因。
- 将候选截断、向量读取和重排分别计时；当剩余预算不足以完成下一轮更新时，返回当前顺序的稳定前缀，并以相关性排序补齐未选位置。
- 相似度特征缺失或服务超时时，使用已批准的相关性稳定排序回退，并写入 `fallback_reason`；不得绕过基础规则。
- 离线比较相关性/NDCG、重复率、意图或类目覆盖、长尾覆盖；线上同时看点击/消费质量、负反馈、候选不足与 P99。

## 常见误解

- **MMR 就是去重**：MMR 是软冗余惩罚，不能保证同实体候选不会同时出现；实体排他性应在基础规则完成。
- **$\lambda$ 越小越好**：过强惩罚会用不相关内容换取表面多样性，必须以用户效用和列表指标共同约束。
- **向量相似度天然可比较**：embedding 模型、归一化方式和发布时间改变时，$\lambda$ 与阈值都应重新验证。
