# 整数规划与拉格朗日方法

当配额、位置与软目标强耦合时，可使用整数规划或拉格朗日松弛。它们适合解决“先按相关性选，再修补配额”持续损失显著的场景，但不能替代[基础规则与约束](../../基础规则与约束/README.md)，也不能在请求 deadline 内无界地搜索最优解。

## 1. 整数规划建模

令 $x_{i,p}\in\{0,1\}$ 表示候选 $i$ 是否展示在位置 $p$，$a_{i,g}$ 表示其是否属于分组 $g$。基础模型为：

$$
\begin{aligned}
\max_x\quad & \sum_{i,p}w_pu_ix_{i,p}
 + \sum_j \alpha_j f_j(x) \\ \text{s.t.}\quad & \sum_i x_{i,p}\leq1 && \forall p,\\
& \sum_p x_{i,p}\leq1 && \forall i,\\
& L_g\leq\sum_{i,p}a_{i,g}x_{i,p}\leq U_g && \forall g\in\mathcal{G}_{hard},\\
& x_{i,p}=0 && \text{for position-ineligible pairs.}
\end{aligned}
$$

$f_j(x)$ 可表示软覆盖、位置偏好或经线性化后的列表目标。硬约束必须保留在求解器约束中；将其仅作为惩罚项会允许求解器用高分候选交换违例。非线性多样性项、重复实体或跨请求曝光状态应先明确是线性化、外层迭代还是交给其他模块，避免在模型描述中含混叠加。

## 2. 拉格朗日松弛与对偶解释

对可软化或近似处理的约束 $c_g(x)\leq b_g$，可引入乘子 $\lambda_g\geq0$：

$$
\mathcal{L}(x,\lambda)=\sum_{i,p}w_pu_ix_{i,p}
-\sum_g\lambda_g\bigl(c_g(x)-b_g\bigr).
$$

固定 $\lambda$ 后，子问题常可分解为带调整分数的排序或小规模选择；再通过次梯度、镜像下降或 warm start 更新乘子。乘子代表约束的边际价格，适合解释软公平、供给倾向等权衡，但不能掩盖强合规、库存、频控或必须满足的下限。松弛后的候选解仍须经过原始硬约束校验与修复。

## 3. 最小可运行示例

- [integer_programming.py](./integer_programming.py) 使用 OR-Tools CP-SAT 实现候选-位置二元变量、候选唯一性、位置唯一性、位置资格和硬类目上下限。
- [lagrangian.py](./lagrangian.py) 使用标准库实现一个可软化类目上限的对偶更新；它刻意不替代硬约束校验。
- [example.py](./example.py) 在同一候选集上执行两种方法，并输出 CP-SAT 的可行解和对偶迭代后的调整结果。

安装 [requirements.txt](./requirements.txt) 中的依赖后执行：

```powershell
python example.py
```

CP-SAT 示例服务于小规模离线验证和模型语义演示：`max_time_seconds` 只限制求解时间，不构成生产 SLA。拉格朗日示例只对**软**上限加入乘子惩罚，硬下限、展示资格和安全规则仍必须在原始可行域或独立校验器中执行。

## 4. 复杂度、空间与线上边界

令 $N$ 为候选数、$K$ 为位置数、$G$ 为分组数、$T$ 为对偶迭代轮数。整数规划一般具有最坏情形指数级搜索成本，变量矩阵至少为 $O(NK)$，再叠加位置资格、分组和线性化辅助变量；不能把“小页面长度”直接等同于可在线精确求解。

若每轮对偶子问题扫描候选并检查 $R$ 个约束，拉格朗日方法常见计算量为 $O(TNKR)$；乘子与计数状态为 $O(G+K)$，但若显式物化 $x_{i,p}$ 或缓存全部特征，空间会升至 $O(NK)$ 以上。具体量级取决于目标能否分解、使用的求解器及 warm start，必须用生产候选规模和最坏规则组合进行压测。

建议为“模型构建、求解、硬约束校验、回退”分别切分预算。精确求解器仅在能于预算内返回已验证可行解时使用；超时时优先采纳其已验证可行 incumbent，否则立即切换到[贪心配额](../贪心配额/README.md)，而不是等待最优性证明。

## 5. 回放、降级与验收

- 记录候选截断规则、完整约束/目标版本、求解器参数、随机种子、warm-start 来源、最优性 gap、incumbent 状态、耗时与回退原因。
- 在求解前检测下限供给不足、互斥位置冲突和无可行候选；在求解后独立验证每条硬约束，防止建模或数值误差直接进入展示。
- 离线与[贪心配额](../贪心配额/README.md)比较位置加权效用、硬约束满足率、软目标损失、求解时间和内存；线上先从严格截断的流量切片开始。
- 若对偶方法未在 deadline 内收敛，使用最近一次通过硬约束校验的解；若没有该解，走贪心基线或显式候选不足路径。

## 常见误解

- **整数规划一定比贪心好**：最优性只相对于正确且完整的模型；错误特征、过期状态或超时回退会抵消理论收益。
- **拉格朗日乘子能处理所有硬约束**：它通常用于可软化约束的近似权衡，安全与资格边界必须在原始可行域中执行。
- **求解器返回结果就代表可展示**：仍需验证库存/合规快照、位置资格和所有硬配额，并记录版本以供回放。
