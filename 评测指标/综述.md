# 推荐系统评测指标综述

## 指标层次

| 层次 | 常见指标 | 回答的问题 |
| --- | --- | --- |
| 召回 | Recall@K、HitRate@K、覆盖率 | 目标是否进入候选，候选是否足够广 |
| 排序 | Precision@K、MRR、MAP、NDCG@K | 相关物品是否排在前面 |
| 预估 | AUC、PR-AUC、LogLoss、Brier、ECE | 区分度与概率校准是否可靠 |
| 列表 | ILD、新颖性、意外性、曝光公平 | 列表是否多样并满足生态目标 |
| 在线 | CTR、CVR、时长、留存、GMV、护栏 | 改动是否因果改善产品目标 |
| 系统 | P50/P95/P99、QPS、可用性、成本 | 方案是否可稳定部署 |

## 常见陷阱

- 随机切分泄漏未来信息，离线结果虚高。
- 将未曝光物品直接当作负例，混淆偏好和曝光策略。
- 只报告全局均值，忽略冷启动、活跃度和长尾分群。
- 只比较 AUC，而系统实际只消费 Top-K。
- 在线实验存在样本比例不匹配、多重检验或提前停止。
- 准确性提升但多样性、公平性、时延或成本恶化。

## 报告规范

至少记录数据时间窗、切分方式、候选协议、负例口径、K 值、宏/微平均、置信区间、分群结果、基线、随机种子和代码版本。在线实验还需记录随机化单位、实验时长、功效分析、SRM 检查和停止规则。
