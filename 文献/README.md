## 整理约定

- 优先记录论文题目、作者、会议或期刊、年份、研究问题和公开链接。
- 阅读笔记应区分论文结论、复现观察与工程经验，并注明数据集和实验口径。
- 同一论文按主要贡献归入一个目录，跨模块关系通过链接说明，避免重复维护。
- 各模块使用哪些指标及如何落地，应在对应模块综述中说明，而不是在文献目录中替代系统设计。
